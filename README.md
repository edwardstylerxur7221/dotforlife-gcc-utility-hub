## Project Overview

DotForLife provides a convenient online starting point for everyday questions, planning, and routine decisions. Visitors can use the platform in either Arabic or English, with content presented for audiences across the GCC.

The site combines practical calculators, informational guides, and comparison-focused material in areas including health, finance, real estate, fitness, plants, and general lifestyle needs. It is delivered as a static website and uses GitHub Actions for deployment, allowing content and updates to be published through a simple workflow.

## Frequently Asked Questions

**Do I install DotForLife as an application?**  
No. DotForLife is a browser-based static website intended for deployment through conventional web hosting.

**Can I use the site in Arabic and English?**  
Yes. DotForLife provides bilingual content for both Arabic- and English-speaking users.

**Which subjects does the platform cover?**  
Its content includes calculators, life tools, guides, and comparisons related to health, finance, real estate, fitness, plants, and other everyday topics.

**What is the update and publishing process?**  
DotForLife follows a static-site workflow with GitHub Actions deployment. Changes to the source can therefore be published through the automated workflow.

**What should I check when a page fails to load?**  
Begin by checking the page files, asset references, and deployment workflow. For local testing, also verify that the browser can access the HTML files and all required static assets.
